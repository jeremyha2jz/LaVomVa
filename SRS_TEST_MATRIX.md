## Alcance de E2E

No se creó una suite E2E de navegador: el repositorio no tiene Playwright/Cypress ni harness web móvil; la UI web de despacho es un marcador informativo y el escáner requiere permisos de cámara. Los flujos principales de servidor sí se recorrieron de punta a punta mediante HTTP de `WebApplicationFactory` contra PostgreSQL real temporal. Esto no equivale a E2E de navegador.
