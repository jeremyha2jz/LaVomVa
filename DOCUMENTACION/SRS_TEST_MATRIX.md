## E2E

Playwright con Chromium ejecuta ocho escenarios en viewport móvil 390×844. `pnpm test:e2e` levanta API y PWA en loopback, crea PostgreSQL temporal desde `BASEDATOS/schema/DATABASE_FINALLL`, crea tickets/QR sintéticos, escanea los PNG reales del endpoint usando una cámara falsa de Chromium y destruye procesos y base al terminar. Los tests cubren credenciales incorrectas/válidas, logout, permisos concedidos/denegados, QR válido/inválido/vencido/consumido, identidad, despacho/inventario, insuficiencia de stock, red caída y installability/cache. No se usó dispositivo físico, producción, email/SMS ni servicios externos.
